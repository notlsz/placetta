# Filing coverage

Generated by `node scripts/filing-coverage.mjs` from `supabase/functions/file/destinations.ts` and the forms registry (`src/forms`). Don't edit it by hand: CI runs the script with `--check` and fails when this file is out of date or a destination has no source page.

The registry has 578 US forms (federal, state, and the 33 metros) and 331 forms abroad, which the Placetta team files.

## How each form would go on its first try

With every channel switched on, a saved login for each portal and a connected mailbox, using the registry's fee and no attachments (`pick()` and `wetPath()` in `supabase/functions/file/logic.ts`). An agency fee keeps a filing off email, fax and mail unless the agency bills it afterwards; a hand signature means the owner signs first, on a page Placetta mails them with one tap.

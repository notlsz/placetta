# Growth: how Placetta wins markets

Read this folder before any work on growth, a new country, a new city, pricing for a market, landing copy for a market
or partners. It is the working playbook; the shared, commentable copy is the Claude Doc "Placetta: winning the top 100
markets" (https://claude.ai/artifact/CzMFG1aHeh6qSHxc3RDEnb). When the two differ, this folder wins: update it first,
then the doc.

| File | What it holds | Change it when |
|---|---|---|
| [PLAYBOOK.md](PLAYBOOK.md) | The strategy: the answer, the scoring model, the waves, the operating system, kill rules | The strategy changes |
| [MARKETS.md](MARKETS.md) | All 100 markets in one table: wave, score, incumbent, who may file, status | A market moves wave or status |
| [markets/](markets/) | One file per market we work on: incumbent, gate, channel, payment, moves, log | Anything is learned about that market |
| [markets/_TEMPLATE.md](markets/_TEMPLATE.md) | The shape every market file follows | Never without updating every market file |
| [research/](research/) | The founder's source research (cases, evidence, draft). Read-only | New research arrives (add a file, don't edit old ones) |

How to work a market (the founder's loop, applied to growth):

1. Open its file in `markets/` (copy `_TEMPLATE.md` if there isn't one) and `MARKETS.md`.
2. Write the done list for the task at the top of the file's log.
3. Compare: what did the winners in `research/` do in this market or one like it? Copy what works.
4. Do it. Check it against the market's metrics and gates. Score it out of 10.
5. Log what happened, dated, newest first. A mistake gets a rule here and in docs/LESSONS.md.
6. Move the market's wave or status in `MARKETS.md` only on the bars in PLAYBOOK.md, never on a feeling.

Facts in these files carry a source link or a † (unverified). Never quote a † fact on the website or to a customer.
